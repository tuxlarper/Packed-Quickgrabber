
# Packed-QuickGrabber

A Python Script Tool To Download Your Favorite Apps In Minutes. no more repo hunting, no more fuss! Currently Supports Debian And Arch Based Distros. Made By @tuxlarper
i also plan to make a script for Windows And More Linux Based Distros.


## Installation

You Can This Script By Simply Downloading The .py file for Your Distro Or Clone This Repo, simply cd into the repo folder or into where you saved the script and run it! (Any Python Version Is Required.)
for example:

```bash
 git clone https://github.com/tuxlarper/Packed-Quickgrabber
 cd Packed-Quickgrabber 
 python3  packed-quickgrabber-arch-pacman.py
```

## Hold Up, you still havent said what this script actually does!
This Script Asks For If You Want To Install Said App And When You Say Yes. It Searches Your Package Manager For The Package And Executes the install command for that app, anfd for some packages (like Mullvad VPN or spicetify) it executes their install script or it will add their repo to your list and install it. depends on your distro
